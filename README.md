# 348-MAKTAB

Raqamli maktab (LMS): o'quvchi, o'qituvchi va administrator kabinetlari, til markazi, SMS eslatmalar, Click obuna.

## Ishga tushirish

1. Bog'liqliklarni o'rnating: `npm install`
2. `.env.example` faylini `.env` ga nusxalang va qiymatlarni to'ldiring (kamida `SESSION_SECRET`).
3. Development rejimi: `npm run dev` → http://localhost:3000
4. Production: `npm run build` va keyin `npm start`
